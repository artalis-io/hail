# Site asset provenance

The Hail landing page adapts the visual language of Keel's repository site:
dark surfaces, fine grids, mint accents, system typography and restrained code
panels. Hail's HTML and semantic stylesheet are specific to its audio contracts.

The H/waveform mark, Open Graph artwork and illustrative duplex traces are
original SVG geometry authored for Hail. They use no third-party icon library,
font or image. The trace is explicitly illustrative, not measurement evidence.

`check_site.pl` is adapted from Keel's offline site checker. The five-file build
retains the same local-asset and reproducibility checks. `.openai/hosting.json`
records the private Sites preview identity; credentials are never source files.

The site is MIT licensed with Hail. `LICENSE` mirrors the repository's root
license so standalone static deployments include the full copyright and
permission notice.
