01 / Architecture

Keep the responsibilities separate.

Transport semantics, execution ownership and native resources meet at a private seam. Application processing stays above it.

01

PCM crosses the boundary.

Opaque streams and neutral, versioned records. SDK buffers, thread handles and native errors stay behind the adapter.

02

Time stays explicit.

Each leg has its own position, clock domain, epoch and uncertainty. Matching sample rates do not imply synchronized clocks.

03

Retirement is a real barrier.

Closed admission is not proof that a native worker has exited. Failed opens retain their accounted storage until cleanup is proven.

02 / Start small

A working duplex example.
No microphone required.

Start with the deterministic virtual backend and a fixed caller-owned arena. Native adapters use the same public contracts.

TerminalCMake · C11
# Build and run the device-free example
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/hail_virtual_example

# Opt into Linux native backends
cmake -S . -B build-linux \
  -DHA_BACKEND_ALSA=ON \
  -DHA_BACKEND_PIPEWIRE=ON

Explicit by default.

The example exercises capture, playback, flush, stale-write rejection and device loss. It allocates from a fixed arena.

  • Default tests do not open native audio streams.
  • macOS enables CoreAudio; Windows enables WASAPI.
  • Linux native builds require backend development packages.
  • Freestanding builds require your allocator and supported atomics.

03 / The contract

Small surface. Observable behavior.

Bounded operations with explicit failure, timing and completion facts.

↔

Independent duplex legs

Different rates, periods and clocks. Playback interruption does not require throwing away the user’s ongoing capture.

▤

Bounded flow

Full capture drops newest. Empty playback produces silence. Loss and underrun counters make both conditions visible.

#

Generation-safe playback

Flush advances the content generation. Old writes are rejected, even if obsolete work finishes after interruption.

⌁

Useful render reference

Selected playback PCM supports external processing. It describes render selection, not guaranteed acoustic presentation.

◷

Honest clock metadata

Positions, domains, epochs, gaps and uncertainty travel with audio. Unknown timing is never promoted to a precise measurement.

□

Accounted memory

One Hail allocation per context and stream, exact plans and no steady-state Hail allocations. Native SDK memory is separate.

Application PCM

Native-endian S16 or F32 · interleaved mono/stereo · 8–192 kHz range

Actual endpoint support is negotiated.
